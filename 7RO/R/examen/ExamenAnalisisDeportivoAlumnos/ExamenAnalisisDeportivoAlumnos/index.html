📋 Pizarra del entrenador · Consideraciones
Te ahorrarán más de un error

    

      
which(): opcionalNo es necesario para el examen, pero aligera cálculos. Devuelve las posiciones donde se cumple una condición; which.max() y which.min() devuelven la posición del máximo y del mínimo.
notas   <- c(4, 8, 3, 9, 6)
alumnos <- c("Ana", "Luis", "Eva", "Iker", "Sara")
which(notas >= 5)          # 2 4 5
which.max(notas)           # 4
alumnos[which.max(notas)]  # "Iker"

      
Ordenar con sort()sort() ordena un vector; con decreasing = TRUE, de mayor a menor. También sirve para ordenar un recuento hecho con table().
tallas <- factor(c("M", "S", "XL", "M", "S", "M"))
sort(c(7, 2, 9), decreasing = TRUE)        # 9 7 2
sort(table(tallas), decreasing = TRUE)[1:2] # M 3 · S 2

      
Tramos con cut()Convierte números en un factor por intervalos. Los tramos son (a, b]: abiertos por la izquierda y cerrados por la derecha.
edades <- c(15, 22, 37, 70)
cut(edades, breaks = c(0, 17, 64, 120),
    labels = c("Menor", "Adulto", "Senior"),
    ordered_result = TRUE)
# Menor Adulto Adulto Senior · Levels: Menor < Adulto < Senior

      
Agregar por grupos con tapply()Aplica una función (media, mediana, suma…) a un vector separado por los grupos de otro.
notas <- c(4, 8, 3, 9, 6)
grupo <- c("A", "B", "A", "B", "A")
tapply(notas, grupo, mean)   # A 4.33 · B 8.5

      
¿No es numérica?Si una gráfica o una correlación falla porque la variable no es numérica, as.numeric(columna) hace la transformación para que R pueda calcular.

      
Quitar filas con NASi un gráfico falla por los valores nulos, na.omit(dataset) elimina las filas incompletas de un data frame.

    

    

      
HISTOGRAMADistribución de una variable numérica continua.

      
BOX PLOTDistribución de una variable numérica por grupos: mediana y cuartiles. Por grupos: boxplot(variable ~ grupo, data = df).

      
BARRASComparar frecuencias o valores agregados (sumas, medias…) de categorías.

      
PIE CHARTProporciones entre categorías.

      
PLOTRelación entre dos variables numéricas, junto a cor(x, y, use = "complete.obs"), que devuelve un valor entre -1 y 1.
